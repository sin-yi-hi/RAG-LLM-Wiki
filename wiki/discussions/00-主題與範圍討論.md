# 討論 00：主題與範圍（還沒生成任何頁面之前）

日期：2026-11-23

## Q1. 為什麼選 RAG？
- 這學期上課講過 LLM 是「猜下一個字」、會有幻覺（hallucination），也有知識截止日期。RAG 正好是業界用來處理這兩個問題最常見的做法，跟課程內容銜接得起來。
- RAG 有原始論文（2020）和綜述論文，也有 AWS / IBM / NVIDIA / Microsoft 等大公司的官方說明，**找得到有公信力的來源**。
- 很巧的是，「LLM Wiki」本身也是一種讓 AI 讀資料再回答的方法，做完可以順便比較兩者。

## Q2. 簡報要給誰看？
- 目標聽眾：**沒學過 AI 技術的大學生**（例如其他系的同學）。
- 所以要：少公式、多比喻、每個技術名詞第一次出現時都要解釋、要有一個從頭走到尾的例子。

## Q4. 不收哪些東西？
- **不使用課堂簡報**當來源（作業要求自己找）。
- 不收沒有作者或機構的部落格、內容農場、二手轉貼文章。
- 不寫程式碼實作細節（聽眾不是工程師），只保留概念。
