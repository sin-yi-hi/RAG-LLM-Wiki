# 名詞解釋

| 名詞 | 白話解釋 | 來源 |
|---|---|---|
| LLM 大型語言模型 | 用大量文字訓練、能生成文字的 AI 模型 | [S2] |
| 幻覺 Hallucination | 模型產生看似合理但錯誤的內容 | [S1] |
| RAG 檢索增強生成 | 先查資料、再根據資料回答 | [S2] |
| 參數記憶 | 存在模型權重裡的知識 | [S1] |
| 非參數記憶 | 存在外部資料庫裡的知識 | [S1] |
| Token | 模型處理文字的基本單位 | [S5][S7] |
| 片段 Chunk | 把長文件切成的小段落 | [S5][S7] |
| 向量嵌入 Embedding | 把文字轉成一串數字，意思相近的數字也相近 | [S2][S6] |
| 向量資料庫 | 存放向量、可快速找出相似向量的資料庫 | [S2] |
| BM25 | 一種關鍵字比對的排序方法 | [S5] |
| 混合搜尋 Hybrid search | 關鍵字搜尋 + 向量搜尋一起用 | [S7] |
| 重新排序 Reranking | 先多撈一些，再精挑最相關的 | [S5] |
| Top-K | 取最相關的前 K 筆結果 | [S6] |
| 微調 Fine-tuning | 用新資料再訓練模型 | [S6] |
| 代理式檢索 Agentic retrieval | 讓 LLM 把問題拆成多個子查詢再去找 | [S7] |
