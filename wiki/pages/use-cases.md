# RAG 的應用場景

| 場景 | 例子 | 來源 |
|---|---|---|
| 人資問答 | Alice 問能不能請半天假，系統查人事資料與請假規定 | [S3] |
| 企業客服 | IBM 用 RAG 讓內部客服聊天機器人根據可查證的內容回答 | [S3] |
| 醫療 | 連到醫學索引的助理，給醫師與護理師使用 | [S4] |
| 金融 | 連到市場資料的金融分析助理 | [S4] |
| 員工訓練 / 技術支援 | 把手冊、影片、紀錄檔變成知識庫 | [S4] |
| 企業內部知識 | 資料分散在 SharePoint、資料庫、雲端，並且要依權限控管誰能查到什麼 | [S7] |

## 共通點（整理）
需要「**最新**」、「**專屬**」、「**能查證**」資訊的地方，就適合用 RAG。
