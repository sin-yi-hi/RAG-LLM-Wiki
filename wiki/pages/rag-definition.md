# RAG 是什麼？

**檢索增強生成（Retrieval-Augmented Generation，RAG）**：讓大型語言模型（LLM）在回答之前，**先去外部資料找相關內容，再根據找到的內容來回答**。

## 各來源的定義（互相印證）
- AWS：在生成回答前，讓 LLM 先參考「訓練資料以外的權威知識庫」，而且不需要重新訓練模型。[S2]
- IBM：從外部知識庫取得事實，讓 LLM 的回答有根據（grounding），也讓使用者看得到依據。[S3]
- NVIDIA：用從特定、相關的資料來源取得的資訊，提升生成式 AI 的準確度與可靠度。[S4]
- Microsoft：把 LLM 的回答建立在你自己的專有內容上的一種模式。[S7]

## 原始論文的說法：兩種記憶
RAG 原始論文把系統拆成兩種「記憶」[S1]：
| | 參數記憶（parametric） | 非參數記憶（non-parametric） |
|---|---|---|
| 是什麼 | 模型權重裡學到的知識 | 外部資料庫（論文用 Wikipedia 索引） |
| 論文中的元件 | BART 生成模型 | DPR 檢索器 + 向量索引 |
| 要更新知識 | 需要重新訓練 | 換掉資料庫就好 |

論文用的知識庫：2018 年 12 月的 Wikipedia，切成 100 字的片段，共 2100 萬（21M）份文件。[S1]

## 一句話記住（整理）
> LLM 是「會寫作的人」，RAG 幫它配了一個「會找資料的助理」。
